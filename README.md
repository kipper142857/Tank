# 双人对战坦克大战
## 游戏介绍
双人同屏实时对战坦克游戏，双方操控坦克展开攻防对决，玩法简单、节奏轻快。

## 游戏规则
- 蓝色坦克位于左上角，红色坦克位于右下角。
- 炮弹撞击墙壁后立即消失。
- 一方炮弹率先击中对方坦克，即可获得1分。
- 坦克被困时，点击左上角小绿旗可刷新地图。

## 操控方式
### 蓝色坦克
- 移动：W、S、A、D
- 发射：Z 键

### 红色坦克
- 移动：方向键 ↑ ↓ ← →
- 发射：空格键

# Tank Battle (2 Player Versus)
## Game Introduction
Two-player real-time tank battle game with simple controls and fast-paced action.

## Game Rules
- Blue tank spawns at top-left, red tank at bottom-right.
- Bullets disappear when hitting walls.
- Score 1 point by hitting the enemy tank first.
- Click the green flag at top-left to reset the map if stuck.

## Controls
### Blue Tank
- Move: W, S, A, D
- Fire: Z

### Red Tank
- Move: Arrow keys ↑ ↓ ← →
- Fire: Space
